# Revisión de `eco4.html`

## Fortalezas
- Propuesta de valor clara y diferenciada (operación + trazabilidad + valorización).
- Alcance de MVP bien acotado.
- Metas cuantitativas definidas para 12 meses.
- Riesgos y mitigaciones documentados.
- Hoja de ruta de 3 años coherente con el enfoque piloto.

## Brechas para pasar a desarrollo
- Faltan reglas de negocio detalladas del flujo de operación (estados, transiciones y validaciones).
- No están definidos requerimientos no funcionales (seguridad, disponibilidad, tiempos de respuesta, backup).
- Falta diseño de datos y diccionario de campos obligatorios por entidad.
- Falta definición legal/operativa de validez del certificado digital.
- Falta estrategia explícita de identidad y permisos por actor.

## Recomendaciones inmediatas
- Convertir objetivos en historias de usuario y criterios de aceptación.
- Diseñar modelo de datos mínimo para piloto.
- Definir stack técnico inicial y arquitectura de despliegue.
- Implementar primero el flujo operativo extremo a extremo y luego blockchain.
