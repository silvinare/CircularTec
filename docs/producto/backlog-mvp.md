# Backlog inicial MVP

## 1) Descubrimiento y definición
- Definir actorías del piloto: generador, recolector/cooperativa, administración municipal.
- Definir taxonomía inicial de residuos (2 flujos prioritarios para piloto).
- Definir reglas de negocio para ciclo de vida de un lote.
- Definir KPI mínimos: operaciones, toneladas, actores activos, distribución por residuo.

## 2) Producto funcional
- Autenticación y roles.
- ABM de actores.
- Publicación de lotes por generador.
- Toma/aceptación de lotes por recolector.
- Flujo de confirmación de retiro con evidencia.
- Emisión de certificado digital por cierre de operación.
- Panel de métricas básicas para administración.

## 3) Datos y trazabilidad
- Modelo de datos para lotes, operaciones, certificados y evidencias.
- Generación de hash por operación cerrada.
- Registro de hash en blockchain (adapter desacoplado).
- Vinculación de tx id con certificado.

## 4) Operación piloto
- Onboarding de 20-30 generadores.
- Onboarding de 5-8 recolectores/cooperativas.
- Soporte operativo y capacitación.
- Monitoreo mensual de adopción y uso.

## 5) Validación
- Criterios de éxito del piloto.
- Tablero de seguimiento mensual.
- Informe técnico de valorización (1 flujo con oportunidad concreta).
