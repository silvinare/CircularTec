# Roadmap - CircularTec

## 1. Objetivo del roadmap

El roadmap busca llevar CircularTec desde un MVP demostrable a una plataforma operativa y escalable para municipios, operadores y redes territoriales.

## 2. Principios de priorización

- primero resolver operación real
- luego ordenar administración y gobierno del sistema
- después reforzar confianza, compliance y escalabilidad
- recién entonces profundizar analítica avanzada

## 3. Fases recomendadas

### Fase 1. Consolidación del MVP operativo

Objetivo:
que un piloto pueda correr con baja dependencia del equipo técnico.

Entregables:

- completar UI operativa para generador, recolector y admin
- mejorar listados, filtros y detalle de lotes
- mejorar detalle de operación y carga de evidencias
- robustecer login, sesión y manejo de errores
- estabilizar métricas básicas

Impacto esperado:

- mejor adopción
- menos soporte manual
- mayor continuidad de uso

### Fase 2. Administración y gobierno

Objetivo:
dar autonomía a la organización que opera la plataforma.

Entregables:

- ABM de usuarios
- ABM de organizaciones
- gestión del catálogo de residuos
- consulta de certificados emitidos
- consulta administrativa de auditoría
- estados y acciones de intervención manual

Impacto esperado:

- menos dependencia del equipo desarrollador
- más control institucional
- mejor calidad de datos

### Fase 3. Confianza, cumplimiento y robustez

Objetivo:
pasar de demo funcional a herramienta institucional seria.

Entregables:

- almacenamiento externo de evidencias
- certificados PDF robustos
- adapter real de blockchain
- backups y políticas de recuperación
- observabilidad técnica
- endurecimiento de seguridad

Impacto esperado:

- mejor auditabilidad
- más confianza para terceros
- preparación para entornos productivos

### Fase 4. Analítica e inteligencia

Objetivo:
convertir operación en información estratégica.

Entregables:

- dashboards avanzados
- evolución temporal por residuo y actor
- reportes ejecutivos
- exportes
- indicadores por territorio
- insumos para detectar masa crítica y oportunidades de valorización

Impacto esperado:

- mejor toma de decisiones
- capacidad de justificar políticas públicas
- valor adicional para clientes pagos

### Fase 5. Escalamiento territorial

Objetivo:
replicar el modelo en múltiples municipios y redes.

Entregables:

- soporte multi-municipio
- parametrización por territorio
- onboarding repetible
- documentación operativa y de despliegue
- soporte y monitoreo estandarizados

Impacto esperado:

- expansión más rápida
- menor costo marginal de implementación
- mejor perfil de negocio

## 4. Roadmap por audiencia

### Lo importante para desarrolladores

- estabilidad del dominio y de la API
- modularidad suficiente para crecer sin reescribir
- ambientes, observabilidad y despliegue más sólidos

### Lo importante para municipios

- simplicidad operativa
- trazabilidad confiable
- visibilidad del programa
- capacidad de gestión sin soporte constante

### Lo importante para inversores

- repetibilidad del modelo
- crecimiento de ingresos recurrentes
- expansión por módulos
- aumento del valor del dato generado

## 5. Señales para pasar de fase

Conviene avanzar de fase cuando ya exista:

- uso real sostenido del flujo operativo
- datos confiables en volumen suficiente
- demanda institucional concreta
- claridad de quién paga y por qué

## 6. Riesgos a monitorear

- agregar complejidad técnica antes de estabilizar operación
- sobrediseñar blockchain o compliance demasiado temprano
- perder adopción por una UI lenta o con demasiados pasos
- crecer en territorios nuevos sin playbook de onboarding
